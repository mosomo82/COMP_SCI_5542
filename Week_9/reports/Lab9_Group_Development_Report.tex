\section{3. APPLICATION ENHANCEMENTS (LAB 9)}

\subsection*{3.1 Lab 6 UI and Stability}
\begin{itemize}[leftmargin=*]
    \item Persistent sidebar, Agent Chat tool-call trace expander, Reset Session button, SQL Explorer error UX.
    \item Snowflake keep-alive ping: cold-start latency $\sim$8s $\rightarrow$ $<$2s. Exponential-backoff retry on all Gemini API calls.
    \item Python logging module replacing print statements. FastAPI \texttt{/health} endpoint + UptimeRobot uptime monitoring.
    \item Agent eval suite expanded 5--10 scenarios with GitHub Actions CI (70\% pass-rate gate).
\end{itemize}

\subsection*{3.2 Lab 7 Benchmarking and Verification}
\begin{itemize}[leftmargin=*]
    \item \texttt{BENCHMARKING.md}: constrained LooGLE run (F1=0.496, consistent with paper's 0.49), HotpotQA subset (F1=0.58 vs paper's 0.61), efficiency verification (37--42\% API call reduction on repeated queries).
    \item \texttt{REPRO\_VERIFICATION.md}: 9 new automated tests across \texttt{test\_benchmark\_smoke.py} and \texttt{test\_repro\_variance.py}. Suite expanded 17--26 tests at zero API cost, fully integrated into CI.
\end{itemize}

\subsection*{3.3 Lab 8 Critical Fixes}
\begin{itemize}[leftmargin=*]
    \item \textbf{CPP Spatial SQL hard gate:} bridge constraint check before any LLM invocation. Monotonicity invariant (APPROVE/VETO on bridge violation) is now deterministic SQL — all 13 metamorphic tests pass.
    \item \textbf{Evidence injection:} \texttt{[RETRIEVED CONSTRAINTS]} block injected verbatim into prompt. Model instructed not to recall limits from memory. Hallucination rate drops from $\sim$40\% to 8\%.
    \item \textbf{Accuracy discrepancy corrected:} baseline was 40\% on both platforms (not 60\% as stated in Section 5 intro). \texttt{EVALUATION.md} documents correct values.
    \item \textbf{CoT-formatted training data:} \texttt{generate\_dataset.py} updated for full 4-step chains. Dataset expanded 100--300+ pairs across 5 disruption types. PEFT CoT quality: 67\% $\rightarrow$ 83\%.
    \item \textbf{Evaluation expanded} 15--50 queries with 5-dimension rubric (0--10). Metamorphic suite expanded 3--13 pairs. GitHub Actions CI added.
\end{itemize}

\subsection*{3.6 Phase 2 Integration (CS5542\_SmartSC\_Optimization\_System)}
All Lab 6--8 components are integrated into the Phase 2 unified system for Research-A-Thon demonstration:
\begin{itemize}[leftmargin=*]
    \item \textbf{CPP agent pipeline (\texttt{src/agents/}):} \texttt{compliance\_agent.py} implements the Spatial SQL hard gate; \texttt{context\_agent.py} wires ReMindRAG into the retrieval layer; evidence injection is applied at the prompt level.
    \item \textbf{Unified Streamlit dashboard (\texttt{src/app/dashboard.py}):} merges Lab 6 analytics tabs (fleet, routes, safety, fuel) with the Lab 8 CPP dispatcher interface. Persistent sidebar, reasoning path expander, and retry decorator applied throughout.
    \item \textbf{Data pipeline (\texttt{src/run\_pipeline.py}):} logging module replaces print statements; \texttt{verify\_pipeline.py} adds row-count and schema assertions for all 4 SILVER tables.
    \item \textbf{CI/CD (\texttt{.github/workflows/ci.yml}):} pipeline smoke test + CPP unit tests + system eval (mock mode) + ReMindRAG 26-test suite — all run automatically on every push with a 70\% pass-rate gate.
    \item \textbf{\texttt{ARCHITECTURE.md} + \texttt{EVALUATION.md} at Phase 2 repo root:} full system-level reference documentation covering the 4-layer architecture, CPP detail, RAG benchmarks, and pipeline evaluation results.
\end{itemize}
